# cnu-planner-docs

충남대 비공식 앱 CNU PLANNER의 개인정보 처리방침과 이용약관을 GitHub Pages로 공개하는 레포입니다. 앱 코드는 [syujin2323/cnu-ai-assistant](https://github.com/syujin2323/cnu-ai-assistant)에 있습니다.

- 공개 주소: https://syujin2323.github.io/cnu-planner-docs/ (처리방침 `privacy`, 이용약관 `terms`)
- `main`에 병합하면 그대로 공개되므로, 문서를 고칠 때는 PR로 올리고 관리자 승인을 받은 뒤 병합합니다.
- 처리방침을 바꾸면 시행일을 고치고, 시행 7일 전부터 알립니다(처리방침 10항).
